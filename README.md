## 🚀 Featured Project

### MediNova: AI Healthcare Decision Support Platform
A multi-condition clinical AI platform that gives automated risk assessments for 7 chronic and infectious conditions, including Diabetes, Heart Disease, CKD, Liver Disease, Breast Cancer and Malaria.

- 📄 **Diagnostic Report Scanner**: OpenCV-based pipeline that extracts lab values from reports and auto-fills the prediction models
- 🔬 **Malaria detection**: CNN (TensorFlow/Keras) for microscopic blood smear images
- 📊 **Tabular models**: optimized scikit-learn ensemble pipelines for clinical data
- 🏥 **Specialist Hospital Finder**: location-based recommendations based on predicted risk category
- 📅 **Appointment booking**: scheduling, Google Sheets logging, instant PDF summaries
- 🐳 **Dockerized** full stack with a responsive dashboard

**Stack:** `Python` `Flask` `TensorFlow` `Scikit-learn` `OpenCV` `Docker`
